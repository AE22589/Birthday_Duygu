## Birthday unlock
The real door unlocks automatically on:
08 September 2026 at 00:00 Europe/Berlin.

The code uses:
2026-09-07T22:00:00Z
because Germany is on CEST (UTC+2) on that date.

## Admin preview hack
Before the birthday, click the locked door 5 times quickly (within 1.5 seconds).

A developer access dialog appears.

Enter:
1337

The countdown is then bypassed and the door becomes clickable.

## Testing
You can therefore test the whole flow at any time:
1. Open index.html.
2. Click the door 5 times quickly.
3. Enter 1337.
4. Click the now-unlocked door.
5. The quest preview appears.

This is a client-side preview bypass, not a security mechanism. Anyone who inspects the JavaScript can find the code.
